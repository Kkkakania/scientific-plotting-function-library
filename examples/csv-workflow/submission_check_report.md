# CSV 工作流投稿前检查报告

## 1. 基本信息

| 项目 | 内容 |
|---|---|
| 数据来源 | `sample_measurements.csv`，合成数据 |
| 图件脚本 | `plot_csv_workflow.py` / `plot_csv_workflow.m` |
| 图件类型 | 双面板时间序列图 |
| 输出格式 | PNG + PDF |
| 目标用途 | 投稿前自查示例 |

## 2. 图件检查

| 检查项 | 状态 | 说明 |
|---|---|---|
| 坐标轴单位 | 通过 | 时间、电压、电流均有单位 |
| 字体一致性 | 通过 | 使用统一字体和字号 |
| 线宽与 marker | 通过 | 主线和 marker 在小尺寸下仍可读 |
| 配色 | 通过 | 蓝/橙组合，灰度下仍有差异 |
| 图例位置 | 通过 | 图例位于右下角，不遮挡主要趋势 |
| 导出格式 | 通过 | 同时导出 PNG 和 PDF |
| 数据边界 | 通过 | 使用合成数据，不含私有路径 |

## 3. 可改进项

- 如果用于真实论文，应按目标期刊要求调整单栏或双栏宽度。
- 如果曲线数量增加，应增加线型或 marker 区分，不要只依赖颜色。
- 如果 CSV 来自真实实验，应保留数据处理脚本和版本记录。

## 4. 结论

该示例适合作为 CSV 到投稿前图件自查的 clean-room 最小流程。真实项目仍需要作者按期刊、导师或课题组要求复核。
