### 关键代码模式（值得吸收进库）

1. **频轴构造惯用法**：`f = ((1:L)-L/2)/L*fs` 配 `fftshift`，一行得到双边频轴；本库 fft_spectrum 用单边，双边版可借鉴。
2. **时移相位补偿**：`Y = fft(y) .* exp(-1j*2*pi/L*(0:L-1)*shift)`，频域平移定理的最简实现。
3. **匹配滤波三件套**（ch10）：`st = exp(1j*pi*K*t.^2)` → `ht = conj(fliplr(st))` → `sout = conv(st,ht)`，配 dB 化 `20*log10(abs(x)/max)`。
4. **LMS 核心五行**（ch7 simpleLMS）：滑动缓存 `xx=[xx(2:M);x(n)]` → 预测 `y=w'*xx` → 误差 `e=d-y` → 更新 `w=w+mu*e*xx`；NLMS 仅多除一个 `xx'*xx` 归一化项。
5. **自写 simple_welch**：`num_segments = floor((N-overlap)/(wlen-overlap))` 的分段计数公式，比黑盒 `pwelch` 更适合教学注释。
6. **手算验证习惯**：DWT 章节每个 `dwt()` 调用旁边都附 `sqrt(2)/2*(s1±s2)` 手算对照——模板注释里"展示公式与函数对账"的写法值得学习。
7. **谱泄漏对比组图**：同一信号 f=16/16.25/16.5 三联 stem 图直观展示非整周期泄漏，是 window_compare 的好补充叙事。

### 对电气专业总体评价

ch3（谐波/暂态频谱）、ch4（滤波器）是电能质量分析的直接基础，五星；
ch6 卡尔曼可平移到电池 SOC 估计与动态状态估计，ch7 自适应滤波即有源电力滤波器 (APF) 的算法内核，四星；
ch10 匹配滤波与行波故障测距同构，ch12 定点化是继电保护嵌入式 DSP 的必修课，三星；
ch8/ch11 与电气主业距离较远。

### AI 工作流与关键代码模式

1. **模板骨架七段式**（每个 AK 文件完全一致）：`clear → load 数据.mat → 颜色定义 → figure('Units','centimeters','Position',[0 0 8 6]) → 绘图+属性 set → 坐标轴调整（Box off / TickDir out / 字体 Arial 8pt）→ print -r300 -dpng`。这与本库 `apply_theme()+make_figure()` 同构，但本库把"坐标轴调整"折叠进了主题函数——架构更优。
2. **AI 协作模式**：书的核心方法论是"让 DeepSeek 写工具函数（配色/取数/转换），人写模板调用"——工具函数都带 `validateattributes` 入参检查和 H1 注释行，是 AI 产出代码的规范化范例。
3. **渐变赋色技巧**（AK 第8章 ribbon）：`set(r, {'CData'}, get(r,'ZData'), 'FaceColor','interp')`——把句柄的 ZData 直接灌给 CData 实现按高度渐变，一行解决，本库 MATLAB 3d 模板可通用。
4. **createGradient 实现**：对 RGB 三通道分别 `interp1(..., 'linear', 'extrap')` 再 clamp 到 [0,1]，与本库 `palette.m` 的 `grad()` 子函数思路一致（本库只支持两端点，书中支持多关键色——已无需求驱动，暂不扩展）。

### 对电气专业实用度：★★★★

模板覆盖电气论文常用图型 80%（本库已全部有对应物且质量更高）；真正的增量是 **AI 写工具函数的工作流**与 ImageDataExtractor 这类"从别人论文图反向取数"的对标工具。
