# 04 Matlab 数学建模常用算法精读

> 资料路径：`17 akun/Matlab数学建模常用算法/`（**只读**，全程未修改原始资料）。
> 精读日期：2026-06-11。读者定位：电气工程本科生（有 Matlab 基础，备战数学建模国赛/美赛）。
> 总规模：41 个顶层算法目录（含 3 个内嵌大工具箱 drtoolbox / 模式分类 100+ / CS_code，实际可数算法 > 150）。
> 质量评级口径：
> - **A**：拿来即用，自带样例数据，无加密/特殊工具箱依赖，看懂注释就能改成自己的题。
> - **B**：能跑但有坑——依赖特定工具箱（神经网络/通信/小波/libsvm）、或数据硬编码需替换、或是 GUI/演示性质。
> - **C**：编码乱码严重 / 残缺 / 仅 .txt 片段 / 强依赖外部加密文件，参考价值 > 直接运行价值。
>
> 共性坑（先读这条，能省一半时间）：
> 1. **中文乱码**：几乎所有 .m 注释是 GB2312 编码，在 UTF-8 编辑器里全是乱码。Matlab 里用 `非Unicode编码=GB2312` 打开即正常，不影响运行。
> 2. **`svmtrain`/`svmpredict`** 指的是 **libsvm**（要单独装并加进 path），不是 Matlab 自带的同名函数——两者参数完全不同，是最常见的踩坑点。
> 3. **`newff`/`newc`/`newlvq`/`train`/`sim`** 来自神经网络工具箱（Deep Learning Toolbox），且新版 Matlab 里 `newff` 已废弃，老代码可能要改成 `feedforwardnet`。
> 4. **`de2bi`** 来自通信工具箱（Communications Toolbox），0-1 规划那两个文件离了它跑不了。

## 二、按类别详解

### A. 预测 / 回归（4 个）

**一元线性回归（#1）** — A
- 原理：最小二乘 `[b,bint,r,rint,stats]=regress(Y,X)`，X 第一列补 1 截距。
- 入口：`一元线性回归代码.txt`（直接复制进 Matlab 跑）。
- 输入：x,y 行向量；输出：系数 b、置信区间 bint、残差 r、`stats=[R², F, p]`。
- 坑与依赖：仅需 Statistics Toolbox；记住 R²→1 越好、p<0.05 才显著。自带 `rcoplot` 残差图判异常点。
- 建模场景：任何"给数据求趋势/外推"的小题；评价类题的预处理。

**Logistic 回归评估还款能力（#2）** — B
- 原理：把 0/1 标签软化成 0.25/0.75 做 Logit 变换 `Y=ln(p/(1-p))`，再用 `regress` 线性拟合，本质是"伪 Logistic"。
- 入口：`Logistic回归模型代码.txt` + `数据.xlsx`。
- 输入：Excel 里的 X(特征)、E 列(0/1 标签)；输出：回归系数 b、新样本判别 0/1(阈值 0.5)。
- 坑：路径写死 `'1.xlsx'`，要把 `数据.xlsx` 改名或改路径；这不是标准 `mnrfit`/`glmfit`，严谨场合建议换官方函数。
- 场景：二分类打分题（违约预测、合格判定、风险评级）。

**AR 油价预测（#3）** — B
- 原理：先做差分让序列平稳，再用自回归 AR(p) 模型外推未来值。
- 入口：`08582053AR/AR.m`。
- 坑：96 期油价**硬编码**在 P/F 两个数组里，换数据要整段替换；阶数靠经验定。
- 场景：平稳时间序列短期外推（价格、负荷、产量）。电气里可类比短期负荷预测的入门版。

**SVM 回归预测上证指数（#15）** — B：见 SVM 条目，回归用 `-s 3` 参数。

### B. 插值（3 个，全 A，国赛"数据补全"必备）

**三次样条（#4）**`spline(x,y,xx)`、**分段线性（#5）**`interp1(x,y,x1,'linear')`、**二维内插（#6）**`interp2(X,Y,Z,XI,YI)`。
- 三者都是 1~10 行的 Matlab 内置函数调用，零依赖、零坑，A 级。
- 输入：已知散点；输出：加密后的插值曲线/曲面。
- 场景：缺失数据填补、采样点加密、地形/温度场重建。`interp2` 还可指定 `'cubic'/'spline'` 提精度。**国赛拿到带空缺的数据表，第一反应就是这三个。**

### C. 分类（12 个，建模"评价/识别"主力）

**KNN（#7）** — A｜原理：算待测点到所有训练点的欧氏距离，取最近 K 个投票。入口 `KNN.m`，自造两簇高斯数据。零依赖，**理解分类思想的第一课**。场景：小样本分类、聚类后打标签。

**Fisher 线性判别 LDA（#8）** — A｜原理：求使"类间散度/类内散度"最大的投影方向 `W=inv(Sw)*(m1-m2)`，投影后一维阈值分类。入口 `Fisher.m`。零依赖。场景：二分类 + 降维可视化；和 PCA 区别（有监督）值得对比理解。

**单层感知器（#9）** — A｜原理：线性可分时迭代 `W=W+y` 修正，直到全部分对。入口 `SinglePerceptron.m`。零依赖。场景：理解神经网络/SVM 的最原始形态。

**二叉决策树（#10）** — B｜入口 `decisionTree.m` 是**手写 if-else 演示**，没有训练过程，只为讲"树怎么判"。真要用树去 `#18` 合集里的 `C4_5.m`/`CART.m`。

**剪辑/压缩近邻（#11）** — C｜`NNforCondense.m` 想精简训练集去噪，但函数体有笔误(`B=dist(1)`)且残缺，看思路即可，别直接跑。

**AdaBoost（#12）** — C｜`adaboost` 目录是 LDA+Boosting 的学术实现，十几个 F_*.m 函数无主入口、注释英文、上手成本高。想用集成学习优先 `#13`。

**BP-AdaBoost 财务预警（#13）** — B｜原理：训练 10 个弱 BP 网络，按错误率加权投票。入口 `Bp_Ada_Sort.m`(分类)/`Bp_Ada_Fore.m`(预测)，自带 data.mat。坑：依赖神经网络工具箱，`newff` 新版要改。场景：预警/分级题。

**SVM 葡萄酒识别（#14）** — B｜原理：`svmtrain`/`svmpredict` 多分类。入口 `chapter12.m`，自带 178×13 wine 数据，含归一化对比演示。坑：**这是 libsvm，必须装并加 path**，否则报错或调到 Matlab 自带的同名函数(参数不兼容)。场景：多类识别（材料/品种/故障类型）。

**SVM 回归上证（#15）** — B｜同上 libsvm，`-s 3` 做 SVR 回归外推。入口 `chapter14.m`(是个 function)，自带上证 4579 天数据。场景：非线性时序回归。

**LVQ 乳腺肿瘤（#16）** — B｜`newlvq` 学习向量量化二分类，入口 `chapter21_lvq.m`，自带 569 例、含交叉验证脚本。依赖神经网络工具箱。场景：医学/质量二分类。

**竞争网络癌症预测（#17）** — B｜`newc` 单层竞争网络做**无监督聚类**，入口 `chapter16.m`。注意它是聚类不是有监督分类。场景：无标签分群。

**模式分类 100+ 合集（#18）** — B｜《Pattern Classification》(Duda)配套库：`Bayesian_Model_Comparison`、`EM`、`C4_5`、`CART`、`Ada_Boost`、各种 `Backpropagation_*`、`Competitive_learning` 等百余个 .m。坑：每个函数独立、接口不统一、需配套书理解。**当"算法字典"查，不当现成模板。**

### D. 聚类（1 个独立 + 散见）

**ISODATA（#19）** — B｜原理：K-means 升级版，迭代中按"类内方差过大→分裂、类间太近→合并"自动调整簇数。入口 `isodata.m`(主函数) + `provaisodata.m`(调用示例) + `dades.mat`。参数多(ON/OC/OS 等门限)是主要门槛。场景：不知道该分几类时；遥感/图像分割。

### E. 降维（4 个，"特征太多"时用）

**drtoolbox 34 种降维（#20）** — B｜原理：统一入口 `compute_mapping(X,'方法名',维数)`，囊括 PCA/Isomap/LLE/LTSA/Laplacian/MDS/Sammon/SNE 等。配 `intrinsic_dim`(估本征维数)、`drgui`(界面)。坑：部分方法要 `mexall` 编译 C 文件；t-SNE 等较慢。**降维想用啥都从这里调**，是本资料库最有价值的工具箱之一。

**八种降维 GUI（#21）** — B｜`mani.m` 流形学习交互界面(MDS/ISOMAP/LLE/HLLE/Laplacian/Diffusion/LTSA)，可视化"瑞士卷"展开。演示教学用。

**t-SNE 可视化（#22）** — B｜把高维(如手写数字像素)降到 2D，`gscatter` 看聚类。入口 `实例/image1.m`。坑：读图路径写死 `D:\image\...`，要改成自己的数据。场景：高维数据"长什么样"的探索性可视化。

**RPCA 异常检测（#23）** — B｜原理：把矩阵分解成低秩 L+稀疏 S，S 即异常/前景。入口 `ALM_RPCA_pub/Onerun.m`，自带监控视频数据。场景：异常值检测、背景建模、故障数据中挑离群点。电气里可用于录波数据异常段提取。

### F. 信号 / 时序分析（3 个）

**小波奇异点检测（#25）** — B｜原理：`wavedec` 6 层 db5 小波分解，高频细节系数 d1~d6 在突变处出现尖峰，定位拐点/突变时刻。入口 `tubian.m`，自带 `A20040101.mat`。坑：需小波工具箱；代码里 `[c,1]=wavedec` 的 `1` 实为变量 `l`(字体混淆)。场景：故障/突变检测——**电气里对应录波信号的扰动起始点定位、暂态检测**，很对口。

**压缩感知（#24）** — C｜OMP/SP/CoSaMP/L1 一大堆重构算法，外加 `CS_code` 里 7 个第三方包(l1magic/GPSR/l1_ls…)。目录里混着 `.log`/`.wav`/`.dat` 垃圾文件，极乱。原理值得了解(欠采样重构信号)，但不建议在这堆里找现成入口。

**RQA 递归图（#26）** — C｜递归图+递归量化分析(判断系统混沌/周期性)，主体在 `递归分析(matlab)` 子目录，需整体引入。冷门，慎用。

### G. 优化 / 智能算法（5 个 + 1 合集，建模"求最优"核心）

**PSO 多目标（#27）** — B｜粒子群解类背包多目标，入口 `main.m`+`data.mat`。坑：是特定题(选物品满足重量约束)的实现，套自己题要改适应度。场景：连续/离散优化通用模板，改适应度函数即可迁移。

**GA 优化 RBF 网络（#28）** — B｜遗传算法当外层优化器，调 RBF 网络的中心 c、宽度 b、权值 w。入口 `Test.m`(训练)、`GA.m`(优化)，自带 `pfile.mat`。坑：二进制编码长度等参数写死。场景：参数寻优 + 函数逼近；"GA 调网络/模型超参"的范式。

**人工鱼群 TSP（#29）** — B｜AF(觅食/聚群/追尾)解旅行商。入口 `FISH_TSP.m`，自带 `att48.tsp`/`ulysses22.tsp`。坑：依赖 `pdist`(统计工具箱)；十几个 AF_*.m 配套函数。场景：路径优化、组合优化；和蚁群/GA 对比理解群智能。

**免疫优化选址（#30）** — A｜原理：模拟免疫系统(抗体浓度调节+交叉变异)解配送中心选址。入口 `main.m`，31 城市坐标+需求硬编码、函数(Cross/Mutation/Select/fitness…)齐全，**直接能跑出收敛图**。场景：选址、设施布局、聚类式优化——本类里最完整可用的一个。

**离散优化合集（#31）** — B｜`离散优化/` 子目录里一站式凑齐：`BNB18`(分支定界)、`DIJKSTRA`(最短路)、`KRUSKAL`/`MINTREEK`(最小生成树)、`LPINT`(整数线性规划)、`DYNPROG`(动规)、`MONTE`(蒙特卡洛)、`ENUM`(枚举)。坑：Kruskal 有 `.c/.dll` 需编译。场景：图论+整数规划题的瑞士军刀。

**动态规划框架（#34）** — B｜通用 `dynprog(x,DecisFun,ObjFun,TransFun)`。坑：要自己写 3 个回调(决策/指标/状态转移函数)，注释里有生产计划完整例子(eg13f1~f3)。场景：多阶段决策(库存、设备更新、资源分配)。

### H. 整数 / 0-1 规划（2 个）

**0-1 枚举法（#32）** / **0-1 隐枚举法（#33）** — B
- 原理：`min c'x, s.t. Ax≤b, x∈{0,1}`。枚举=遍历 2ⁿ 种组合；隐枚举=带剪枝(发现违约即跳过)更快。
- 入口：`L01p_e.m` / `L01p_ie.m`，注释里有 `c=-[3,5,2,4,2,3]` 背包样例。
- 坑：都靠 `de2bi`(**通信工具箱**)把整数转二进制串；n 大于 ~20 时 2ⁿ 爆炸。
- 场景：选址(选/不选)、指派、背包类决策题。

### I. 图论（3 个，全 A，国赛网络题硬通货）

**BFS 广搜（#35）** — A｜邻接矩阵分层遍历，求最短跳数/连通性。入口 `BFS.m`，注释含迷宫样例。零依赖。

**最小费用最大流 BGf（#36）** — A｜`[f wf zwf]=BGf(C,b)`，C 容量矩阵、b 单位费用，Busacker-Gowan 迭代求最小费用流。**纯函数无依赖**，输入两矩阵即得最优流。场景：运输调度、网络流分配——**电网潮流/配送网络题非常对口**。

**全染色图优化（#37）** — A｜`[k C W]=graphcodf(M)`，对点和边同时染色求色数 k。入口邻接矩阵 M。零依赖。场景：排课、频率分配、任务调度冲突避免。

### J. 传染病模型（4 个，国赛/美赛高频题型）

**SI/SIS/SIR 微分方程（#38）** — A｜原理：经典仓室模型 ODE，`ill.m` 定义方程组 `dS/dt`、`dI/dt`，主程序用 `ode45` 解。入口 `ill.m` + Word 说明文档。零依赖、可直接出曲线。**做传染病/谣言传播/信息扩散题的标准起点**，电气里可类比级联故障扩散建模。

**蔓延模型（#39）** — C｜**注意：此目录名不副实**，里面 `mani.m` 其实是流形降维 GUI(和 #21 完全一样)，与传染病无关，跳过。

**网络病毒传播 SIR（#40）** — B｜在网络拓扑(邻接矩阵)上按 BFS 逐节点传播 SIR，入口 `spreadingBySir.m`+`test.in`。比连续 ODE 更贴近"个体网络"。场景：复杂网络上的扩散、电网节点级联失效。

**城市网络 SIS 仿真（#41）** — B｜城市内 SIS 解析迭代 + 城际人口流动耦合 + 城市间最短路(Floyd)。入口 `sis.m`，需先给城市邻接矩阵 A。场景：带空间结构/迁移的传播题。

## 四、给电气本科生的优先级建议

**最该先吃透的 3 个（按"性价比 = 通用性 × 易用性"排序）：**

1. **插值三件套（#4/#5/#6）** — 几乎每道数据题都会用到，且是零依赖、零坑的 Matlab 内置函数，10 分钟掌握、终身受用。先学这个最划算。
2. **SI/SIS/SIR 传染病 ODE 模型（#38）** — 国赛/美赛高频独立题型，代码用 `ode45` 一跑就出图，原理(仓室微分方程)和电气里学的"状态方程/暂态过程"完全同构，迁移成本极低，还能自己扩展成 SEIR、级联故障模型当亮点。
3. **最小费用最大流 / 图论三件套（#36/#35/#37）** — 纯函数、无任何工具箱依赖、输入邻接矩阵即得最优解；网络流/最短路与电气专业的潮流计算、配电网规划、可靠性分析高度对口，是把专业背景写进建模论文的最佳切入点。

> 次优先：免疫选址(#30，最完整的智能优化范例)、drtoolbox 降维(#20，降维一站式)、PSO/GA(#27/#28，掌握一种群智能即可触类旁通)。
> 可暂缓：压缩感知(#24)、RQA(#26)、AdaBoost 学术版(#12)、近邻剪辑(#11) —— 这些 C 级目录乱码/残缺/依赖重，投入产出比低。
